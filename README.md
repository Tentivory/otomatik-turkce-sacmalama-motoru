# Otomatik Türkçe Saçmalama Motoru

## Bu Ne Lan?

Bu repository, insanlığın en büyük sorunlarından biri olan "mantıklı cümle kurmak" hastalığına karşı geliştirilmiş, dünyanın (asılında evrenin) en abartılı, en ciddi, en saçma Türkçe cümle üreticisidir.

Gerçekten çalışır. Gerçekten saçmadır. Gerçekten hiçbir işe yaramaz. Mükemmel.

## Nasıl Kullanılır?

```bash
python sacmalama_motoru.py
```

Çalıştırdığınız anda Türkçe'nin sınırları zorlanır, beyin hücreleriniz isyan eder, komşunuz "bu ne ya" der.

## Özellikler

- Tamamen Türkçe saçmalık üretir.
- Rastgele nesneler, rastgele eylemler, rastgele yerler.
- Hiçbir mantık aramayın, bulamazsınız.
- Patates içermez. (kullanıcı öyle istedi)
- Gizli mesajlar içerebilir veya içermeyebilir. (içerir)

## Uyarı

Bu yazılımı kullanmak zihinsel sağlığınıza zarar verebilir. Sorumluluk kabul etmiyoruz. Hatta sorumluluk diye bir şey yoktur bu repoda.
